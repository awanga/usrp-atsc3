# test/captures/

IQ capture fixtures used by the capture-replay integration tests
(`test/integration/test_iq_replay.cc`, `test/integration/test_signal_chain.cc`).
Tracked via git-lfs (`*.sigmf-data`, `*.sigmf-meta`); run `git lfs pull`
before running these tests locally.

**Not currently checked into this branch.** The dev environment this
branch was pushed from has outbound network access to `github.com` but
not `lfs.github.com`, so `git lfs push` cannot complete from it (the
batch/upload stages succeed, the final per-object `verify` call to
`lfs.github.com` is rejected by the environment's network policy). Rather
than block the RTL/test work on that, the two fixture files were removed
from this branch's history; `test_iq_replay.cc`/`test_signal_chain.cc`
already `GTEST_SKIP()` when no capture is present, so the rest of the
suite is unaffected. Regenerate them locally with
`scripts/generate_synthetic_capture.py` (below) and `git lfs push` from
an environment that can reach `lfs.github.com`, or check them in from a
machine without that restriction.

## Provenance

`ch35_10sec_20260503_222404.*` and `ch35_20sec_20260724_050312.*` are
**synthetic fixtures**, not off-air recordings. There is no ATSC 3.0
broadcast hardware in this project's CI/dev environment, so no genuine
capture exists to check in. (Earlier versions of these files were
committed as if they were real hardware captures; they turned out to
contain a sustained narrowband tone rather than a real bootstrap burst,
which the falling-edge peak-tracking detection FSM -- built for a brief,
one-shot burst -- never fires "detected" on. They were regenerated from
scratch as honestly-labeled synthetic fixtures.)

Both files are generated by `scripts/generate_synthetic_capture.py`:
complex Gaussian "OFDM-like" fill at a fixed power level, with a
Schmidl-Cox-style repeated-half bootstrap burst (CP + three repeats of a
2048-sample half symbol) spliced in every 1000000 samples starting near the
top of the file, the whole buffer rotated by one continuous ~973 Hz CFO
tone so the correlation math is exactly self-consistent with
`BootstrapDetector`'s own model. Three repeats (not the spec's two) give
the detector's EWMA (1024-sample time constant) enough settling time to
clear the integration tests' `metric > 0.9` assertion; see the script's
module docstring for the derivation. This is a fixture for exercising the
pipeline end-to-end, not a spec-conformance vector -- those live in
`test/compliance/`.

The filenames' `_10sec_`/`_20sec_` labels are provenance only, not actual
duration: git-lfs storage for this repo is capped, so both files are
generated at 0.5s/1.0s (a few burst periods past the deepest scan window
any capture-replay test reads) rather than their original 10s/20s, which
would re-add the ~2GB a previous commit ("Cull IQ captures to fit within
2GB LFS limit") had already trimmed away. Renaming was skipped to avoid
touching every test/doc reference to these two specific filenames; if
that ever gets revisited, do it in the same pass as an actual filename
rename, not silently.

To regenerate both files (deterministic given the fixed RNG seed in the
script):

```bash
python3 scripts/generate_synthetic_capture.py
```

Then update `atsc3:validation` / `annotations` in the corresponding
`.sigmf-meta` if the generation parameters changed, and verify detection
against the real library before committing, e.g.:

```bash
cmake --build build -j$(nproc) --target atsc3_lib atsc3_hal
g++ -std=c++17 -O2 -I lib -I lib/sync -I hal/include \
    <(cat <<'EOF'
#include "bootstrap_detector.h"
#include "iq_source_factory.h"
#include <cstdio>
int main(int argc, char** argv) {
    auto src = atsc3::hal::create_file_source(argv[1], std::stod(argv[2]), false);
    atsc3::sync::BootstrapDetector det({});
    std::vector<atsc3::sample_t> buf(4096);
    size_t total = 0;
    while (total < 1000000) {
        size_t n = src->read(buf.data(), buf.size());
        if (!n) break;
        for (size_t i = 0; i < n; ++i) {
            auto d = det.process(buf[i]);
            if (d.detected) printf("detected @%zu cfo=%f metric=%f\n", total+i, d.cfo_hz, d.metric);
        }
        total += n;
    }
}
EOF
    ) build/hal/libatsc3_hal.a build/lib/libatsc3_lib.a -o /tmp/verify_capture
/tmp/verify_capture test/captures/ch35_20sec_20260724_050312.sigmf-data 6.25e6
```
